Expense Tracker

Project Description

The Expense Tracker is a simple web application that helps users record and manage their daily expenses. Users can add expenses with a description, amount, and category, view the list of recorded expenses, delete expenses, and calculate the total amount spent.

The application also allows users to filter expenses by category and stores data using the browser's Local Storage so that expenses remain saved even after refreshing the page.

---

Features

- Add a new expense with description, amount, and category
- View all recorded expenses
- Delete an expense from the list
- Calculate and display the total expenses
- Filter expenses by category
- Save expenses using Local Storage

---

Technologies Used

- HTML – For creating the structure of the application
- Tailwind CSS – For styling and responsive design
- JavaScript – For implementing the application logic
- LocalStorage API – For storing expenses in the browser

How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open the "index.html" file in your web browser.
4. Start adding and managing your expenses.

---

Example Usage

1. Enter the description, amount, and category of an expense.
2. Click Add Expense.
3. The expense will appear in the list.
4. The total expenses will update automatically.
5. You can filter expenses by category or delete an expense.
